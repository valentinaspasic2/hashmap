# Hash Map
A custom C++ HashMap implementation using linked lists to handle collisions, dynamic resizing, and key value operations.

## How it works
The HashMap uses a hash function to assign keys to buckets. Linked lists handle multiple keys that map to the same bucket.

It supports inserting, retrieving, searching, and removing key value pairs. The table automatically resizes and rehashes its entries when the load factor becomes too large.

The project also includes copy operations, equality comparison, and iteration through stored key value pairs.
